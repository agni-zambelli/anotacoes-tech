# 🧠 SUPER COLA


| O que quero fazer   | Markdown          |
| ------------------- | ----------------- |
| Título principal    | `# Título`        |
| Subtítulo           | `## Subtítulo`    |
| Negrito             | `**texto**`       |
| Itálico             | `*texto*`         |
| Lista               | `- item`          |
| Checklist pendente  | `- [ ] tarefa`    |
| Checklist concluído | `- [x] tarefa`    |
| Link                | `[nome](link)`    |
| Imagem              | `![nome](imagem)` |
| Código pequeno      | `` `código` ``    |
| Bloco de código     | ` ``` `           |
| Citação             | `> texto`         |
| Linha separadora    | `---`             |
